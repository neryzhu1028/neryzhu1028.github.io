如何创建访问令牌？
  1. 打开 GitHub → Fine-grained tokens
  2. 点 Generate new token，名称随意（如 aceskills-cms）
  3. Repository access 选 Only select repositories，选中 neryzhu1028.github.io
  4. Permissions → Repository permissions：将 Contents 设为 Read and write（必需）
  5. 生成后复制令牌（以 github_pat_ 开头），粘贴到上方输入框
  6. 建议有效期设为 90 天，到期后重新生成即可
